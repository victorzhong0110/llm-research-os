# Remote native outcome examples

The valid request reports an already-bound Worker-local observed exit. It alone
does not prove the OS observation or output: the controller additionally requires
its immutable start record and the completed verified output for this phase.
`request.invalid-unobserved.json` is invalid because a terminal outcome requires
`observation: exited`. `receipt.invalid-launch.json` incorrectly grants launch
permission; all receipts have literal `launchAllowed: false`.
